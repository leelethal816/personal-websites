02 / About

Build once.
Improve what’s next.

My work starts with a simple question: how can we make this more consistent, repeatable, and useful?

I’ve worked on large-scale hybrid infrastructure spanning Oracle Linux, SUSE, Red Hat, and Ubuntu. I use Ansible, Terraform, Python, and Bash to automate provisioning, patching, configuration, and OS upgrades, and contribute to cloud migration and infrastructure modernization.

I also develop AI agents for workflows across Linux servers, containers, and infrastructure environments. Alongside GCP, Kubernetes, OpenShift, and GitOps, I’m exploring how AI and traditional automation can make infrastructure easier to build, deploy, and manage.
